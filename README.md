## 基础规则

```text
TreeLearning 根节点：全局基础知识
├── 项目 A：学习内容（可选）
│   ├── 文件：教材正文
│   │   └── 问答：问题 + 回复
│   │       ├── 问答：继续追问
│   │       └── 文件：补充资料
│   └── 问答：另一个独立分支
└── 项目 B
```

- 根节点下只能创建项目。文件和问答都可以作为项目、文件或问答的子节点。
- 左侧只显示当前节点、直接父节点和直接子节点；点击名称或箭头会切换当前节点并重建列表。搜索限定直接子节点，不展开孙节点；顶部路径仍可跳转任意祖先。
- 源码新增：消息区域到达顶部后继续向上滚动，可返回直接父节点。支持滚轮、触控板和触摸；一次手势只返回一级，根节点不再向上切换。左下角装饰图片已移除。这些修改尚未打包到安装版。
- 学习树图以当前所属项目为起点，从左向右横向生长，仅显示该项目及其后代。根节点页面显示项目列表，不提供全局树图。
- 每次提问新建一个问答节点。上下文严格等于根节点到当前节点的唯一祖先路径，包含当前节点本身；兄弟分支、其他项目不会自动加入。
- 源码新增：AI 在同一次请求中返回问题的简短概括和完整回复，概括用于节点名称；不改变问题原文。自动名称可随重新生成更新，手动改名后保留。模型未返回有效标题时保留原名称；演示模式不调用 AI。这项修改尚未打包到安装版。
- 根节点正文作为系统消息；项目正文作为用户资料消息；问答节点发送问题和回复。文件节点仅发送名称、标识和长度，正文通过工具按需读取，历史阅读快照也不自动发送。模型请求附加标题和回复格式指令，可在调试模式查看完整实际请求；不使用服务端会话历史。
- 重新生成叶节点回复时，保留所有祖先内容和当前问题，仅排除当前节点旧回复。
- 只有叶节点可编辑名称和内容，包括已发送的问题与回复；问题旁提供“修改发送内容”入口。修改保存后可重新生成回复。有子节点时锁定编辑，删除全部子节点后恢复编辑。
- 非根节点均可删除；确认框显示包含自身的删除总数，确认后删除全部后代并返回父节点。取消不会更改数据。根节点不能删除。
- 生成期间锁住所有树修改；可停止生成，失败或取消保留旧回复。服务端同时执行这些检查。

## 启动

开发环境需要 Node.js 22.19 或更新版本。

```bash
npm ci
npm run desktop
```

这会构建并打开 Electron 桌面窗口，无需单独启动浏览器或服务端。桌面版适用于 Windows、macOS、Linux；安装包在对应平台构建。

浏览器开发入口：

```bash
npm run dev
```

打开 http://127.0.0.1:5188 。通过 `PORT` 环境变量修改端口。本地服务只监听 `127.0.0.1`。

## 模型设置

默认使用 **AI 模式**。在“模型设置”填写 API 地址、模型 ID 和密钥，可使用 Chat Completions 或 Responses API，也可连接不需要密钥的本地兼容服务。支持直接填写基础地址或完整端点地址。未配置接口时会提示先配置，不会自动生成演示回复。

模型设置提供三种模式，切换不会改变已有节点：

- **AI 模式**：正常调用模型。
- **演示模式**：不调用模型，回复明确标注“未调用 AI”。
- **调试模式**：正常调用模型，顶部“查看 API 请求”显示请求地址、应用设置的请求头、完整 JSON 正文及请求状态。正文来自实际发送的同一份序列化数据，支持复制和导出；Authorization 密钥会遮蔽。等待、失败或取消的请求也可查看。

调试记录只保留本次运行最近 20 次请求，不写入学习树或磁盘，退出程序或切换到其他模式后清除。升级时保留旧版已保存的 AI／演示模式选择，新安装默认为 AI 模式。

Responses API 使用 `store: false`、`truncation: "disabled"`，逐次发送完整路径，不使用 `previous_response_id`。文件工具的后续请求会携带本次调用及工具返回内容，Responses 同时保留推理输出项。没有本地生成超时，支持主动停止。第一版等待完整文本返回，暂未实现流式输出和图片理解。

密钥默认只存在本地服务的内存中，退出程序后清除。勾选“在本机保存密钥”后会明文保存在本机设置文件中。完整学习树备份不包含密钥。没有内置密钥，未使用真实收费接口进行验证。

## 文件和数据

### 节点导航与项目笔记（0.1.7）

顶部后退／前进支持 `Alt+左／右`，快速跳转支持 `Ctrl+K`（macOS 也支持 `Cmd+K`）。默认搜索当前项目的节点名称与问题，可切换全部项目；空查询显示最近访问。切回节点会恢复阅读位置和未发送的问题草稿。

右上角笔记图标打开可折叠、可调宽的项目笔记栏，窄屏使用独立笔记视图。每个项目可新建多份命名笔记；笔记不属于对话节点。浏览其他节点或项目时，正在编辑的笔记保持不变；通过“项目笔记本”搜索、选择、新建或导出 Markdown。编辑后 800ms 自动保存，支持 Markdown 预览、复制粘贴、摘录问题／回复和选中文字；摘录保留可点击的来源节点链接。

笔记默认不进入 AI 上下文。同一项目内可用“引用笔记到问题”将当前笔记快照放入问题草稿，确认发送后才进入对话；修改原笔记不会改写历史问题。文件工具仍只读取当前节点及祖先路径的文件。

笔记随完整 ZIP 备份保存。删除普通节点不删除笔记，删除项目会在确认后删除其全部笔记；失效的来源链接会提示。并发保存冲突不会覆盖新内容，失败草稿可重试、复制或另存为新笔记。浏览器保留本机草稿，桌面版还通过 `workspace-state.json` 保存导航、问题草稿及笔记编辑状态，正常退出会等待保存完成。跨机器搬迁正式笔记使用完整 ZIP；未保存的恢复草稿请先另存或导出。

相关功能已通过 22 项核心／服务端测试、8 项浏览器流程及新增的键盘与提示音专项测试。0.1.7 仅生成 Windows 免安装版。

消息输入框中 Enter 发送，Shift/Ctrl+Enter 换行；中文输入法确认文字不会误发送。回复成功保存后播放短提示音，失败或取消不响。文件节点仅显示引用信息，右上角“显示上下文”直接打开上下文弹窗。

0.1.6 已包含联网工具。模型设置中打开“联网搜索”，默认使用 **OpenAI 内置搜索**，接口自动切换为 Responses API。搜索复用当前 API 地址、模型和密钥，向所配置中转站的 `/responses` 端点发送 `tools: [{type: "web_search"}]`，不会绕过中转站直连 OpenAI，也不需要 Tavily 密钥。中转站和所选模型必须支持该内置工具；仅支持 Chat Completions 或普通函数调用的中转站不一定可用。不兼容时显示错误，不会静默改用其他服务。参见 [OpenAI Web Search](https://developers.openai.com/api/docs/guides/tools-web-search)。

“搜索服务”也可选择 **Tavily**，这种方式需要独立的 Tavily API 密钥，支持现有的两种接口。已有 Tavily 密钥的旧配置自动保留该服务。搜索和网页提取可能消耗相应服务的额度；参见 [Tavily Search](https://docs.tavily.com/documentation/api-reference/endpoint/search) 和 [Tavily Extract](https://docs.tavily.com/documentation/api-reference/endpoint/extract)。以下自定义联网工具仅用于 Tavily：

- `web_search`：检索公开网页，每次最多 5 条结果，返回标题、URL 和摘要。
- `read_web_page`：提取公开网页文字，每次最多 2 万字符，截断会明确标记；不下载本机或内网文件。
- `list_branch_files`、`search_branch_files`、`read_branch_file`：列出、检索和按需读取当前节点及祖先路径中的文件，包括已导入并提取文字的 PDF。不能跨分支读取。

Tavily 每次回答最多执行 8 次联网工具，单次联网超时 20 秒。OpenAI 搜索由中转站执行，使用 `max_tool_calls` 提交剩余调用额度（初始 8 次），达到额度后在后续请求中移除搜索工具；实际执行由服务端实现决定。停止生成会取消本机正在等待的请求。调试模式显示实际请求和工具调用记录，包括 OpenAI 返回的 `web_search_call`。回答下方保存 OpenAI `url_citation` 或 Tavily 来源链接，来源随学习树备份保存，不自动把网页正文加入后续上下文。文件工具仍只能读取当前节点及祖先路径，演示模式不执行联网请求。

模型密钥和 Tavily 密钥共同遵循“在本机保存密钥（明文）”设置，默认退出后清除。仅选择 Tavily 时要求补充独立搜索密钥。联网服务使用模拟响应验证，新增 OpenAI 中转站测试覆盖路径、密钥复用、与文件工具组合调用、来源保存、调试记录及不兼容错误；尚未使用真实中转站完成外部搜索。当前共 21 项核心／服务端测试。

支持文本型 PDF、DOCX、Markdown、UTF-8 TXT、CSV、JSON 和常见代码文件。已取消本地文件的 15 MB 和 30 万字符上限。上传流式写入磁盘，原文件和提取的正文独立保存在文件库中，界面和 AI 分段读取；树节点只保存文件引用。文本文件增量解析，PDF、DOCX 在独立工作线程中解析，极大文档仍受可用内存和磁盘空间影响；扫描 PDF 需要先 OCR。当前节点及祖先路径中的文件正文仅在 AI 调用工具读取后进入本次请求，不自动展开全文；路径之外的文件无法列出、搜索或读取，即使属于同一项目。超过 50 万字符的初始模型上下文会报错，不会静默截断。

### AI 按需阅读分支文件

将资料添加为文件节点，然后在该文件下提问或从它的后代问答继续，例如“查阅这份教材，解释线性组合的定义”。AI 模式与调试模式均提供三个只读工具：`list_branch_files` 列出路径内文件、`search_branch_files` 查找关键词、`read_branch_file` 分段读取。模型需要支持 Function Calling。权限由服务端按根节点到当前节点的唯一路径校验，不能读取兄弟分支、当前节点的后代、其他项目或任意磁盘路径，也不执行文件中的代码。只在项目节点提问时，项目下面的文件尚不属于当前祖先路径。

每次读取最多 2 万字符，返回全文长度和下一段偏移，不会将片段标记成全文；一次问答最多读取 20 万字符、执行 32 次工具调用及 8 轮工具交互。达到限制会要求模型根据已读取内容作答，或明确报错。

回答下方“本次阅读”可展开查看实际读取的片段。成功回答会将片段作为该问答节点的阅读记录保存，并纳入备份和 Markdown 导出，但不会自动加入后续模型上下文。后续追问或重新生成需要时会再次读取路径内文件。旧版已有阅读记录保留供查看，也不再自动发送；历史问题和回复保持不变。失败或取消保留原回答和原阅读记录。

调试模式记录每轮实际 API 请求以及文件工具调用、参数和返回值。协议参考 [OpenAI Function Calling 文档](https://developers.openai.com/api/docs/guides/function-calling)。

数据保存为 `tree.json`，写入采用临时文件后原子替换；并发操作通过版本号检查。桌面版使用 Electron `userData` 目录，通常位于：

- Windows：`%APPDATA%/treelearning/`
- macOS：`~/Library/Application Support/treelearning/`
- Linux：`~/.config/treelearning/`

开发浏览器版保存到项目的 `.local/`，可通过 `TREELEARNING_DATA_DIR` 指定其他目录。桌面和浏览器开发版的数据默认独立，可用完整 ZIP 备份迁移。`documents/` 保存原文件和分段正文，搬迁数据时不能只复制 `tree.json`。

左下角可导出包含学习树和文件库的完整 ZIP 备份，也兼容恢复旧 JSON。右侧可导出当前路径的 Markdown，其中保留文件元数据和已读取片段，不展开整份文件。恢复前校验树结构和文件完整性，并将现有树自动备份为 `tree-before-restore-时间戳.json`。首次加载旧内嵌文件时自动迁移，并保留 `tree-before-file-migration-时间戳.json`。删除或替换节点后暂不回收旧文件，以便本机历史树备份仍可恢复；这些 JSON 历史备份依赖原文件库，跨机器迁移请使用完整 ZIP。
