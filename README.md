# TreeLearning 树学(测试阶段)

## 项目介绍

TreeLearning（树学）是一款用树状结构组织学习资料、AI 对话和学习思路的伴学软件。你可以围绕同一主题不断追问，也可以创建独立分支探索不同问题，避免无关内容混入上下文。

学习空间由根节点、项目、文件和问答组成。根节点提供全局基础知识，项目可补充学习目标与课程内容，文件和问答则按需要继续分支。AI 回答时只使用当前节点及其历代父节点的上下文，不自动读取兄弟分支或其他项目。

软件采用跨平台桌面架构，目前优先提供 Windows 免安装版。学习树、文件和笔记保存在本机，AI 服务由使用者自行配置。

## 主要功能

- **树状学习与分支对话**：文件与问答采用相同的树结构，AI 自动概括问题作为节点名称。不同分支可同时生成回复，停止某个节点的任务不会影响其他分支。
- **按需阅读文件**：支持文本型 PDF、DOCX、Markdown、UTF-8 文本及常见代码文件。文件以引用形式展示，AI 可按需检索、分段读取当前节点及祖先路径中的文件，不会默认将全文加入上下文。
- **节点导航**：支持后退／前进、`Alt+左／右` 和 `Ctrl+K` 快速跳转。切换节点时恢复阅读位置和问题草稿；左侧导航可收起，项目学习树从左向右展示，直接子节点以短标题按钮显示在输入框上方。
- **项目笔记**：每个项目可建立多份 Markdown 笔记，支持自动保存、编辑／预览、搜索和导出。浏览其他节点时可继续编辑原笔记，也可摘录整条问题或回复并保留来源链接。
- **引用与复制**：选中问题或回复中的文字后，右键菜单出现在选区附近，可引用到问题草稿或复制。笔记也可手动引用到同一项目的问题草稿，引用后由使用者确认发送。
- **模型与联网工具**：支持 OpenAI 兼容的 Chat Completions、Responses 接口及中转站。可选择 OpenAI 内置搜索或 Tavily 搜索，并查看回答引用的网页来源。
- **阅读与输入体验**：回复支持 Markdown 和数学公式。`Enter` 发送，`Shift+Enter` 或 `Ctrl+Enter` 换行，回复成功完成后播放提示音。
- **本机保存与备份**：支持导出和恢复包含学习树、文件及项目笔记的完整 ZIP 备份，也支持项目笔记的 Markdown 导出。

## 安装方法

当前 Windows 免安装版本为 **0.1.9**，适用于 Windows 10／11 x64。

1. 获取 [TreeLearning-0.1.9-Windows-x64.zip](release/windows/TreeLearning-0.1.9-Windows-x64.zip)。
2. 将压缩包完整解压到一个文件夹，不要直接在压缩包中运行程序。
3. 双击解压目录中的 `TreeLearning.exe`，无需另外安装 Node.js 或启动服务。
4. 打开“模型设置”，填写 API 地址、模型名称和密钥，并选择服务商支持的接口类型。没有可用接口时，可先切换到演示模式体验。
5. 创建项目，按需要添加学习内容或文件，然后开始提问。若希望 AI 阅读某份文件，请在该文件节点下或其后代节点继续对话。

升级时先退出旧程序，将新版解压到独立目录后运行。默认本机数据目录不随程序目录改变，原有学习数据会继续读取；升级前建议导出完整 ZIP 备份。

需要从源码运行时，安装 Node.js 22.19 或更新版本，在项目目录执行：

```bash
npm ci
npm run desktop
```

也可执行 `npm run dev`，在浏览器中打开 `http://127.0.0.1:5188`。浏览器开发版与桌面版默认使用不同的数据目录，可通过完整 ZIP 备份迁移。更多说明见 [Windows 使用说明](WINDOWS.md)。当前不提供与此版本同步验证的 macOS、Linux 安装包。

## 注意事项

- **上下文范围**：项目中存在某份文件，并不意味着所有分支都能读取它。文件必须位于当前节点到根节点的路径上。笔记默认不进入 AI 上下文，只有手动引用并发送的快照才进入对话；后续修改笔记不会改变历史问题。
- **编辑与删除**：只有叶节点可修改问题、回复及节点内容；已有子节点的历史节点保持锁定。删除节点需要确认，并会一并删除其后代。删除项目也会删除项目笔记。生成中的节点及其祖先受到保护，其他分支仍可操作。
- **接口兼容性**：文件阅读需要模型支持工具调用；OpenAI 内置搜索需要模型支持 Responses API 的搜索工具，Tavily 则需要单独的搜索密钥。软件不附带 API 密钥，调用费用和可用额度由所选服务决定。
- **数据与密钥**：学习数据保存在本机，但提问时必要的上下文、读取的文件片段及手动引用内容会发送给配置的模型服务。密钥默认仅在本次运行中保存；勾选本机保存后会以明文写入设置文件，完整学习 ZIP 备份不包含密钥。
- **备份与迁移**：Windows 默认数据目录为 `%APPDATA%/treelearning/`，可通过“文件 → 打开数据文件夹”查看。跨设备迁移请使用完整 ZIP 备份，不要只复制 `tree.json`，因为文件资料保存在独立文件库中。退出前应确认笔记保存成功。
- **测试阶段**:目前该软件仍处在测试阶段,可能会出现包括但不限于软件破坏性更新,恶性软件bug,体验不佳等问题,如有bug欢迎提issue.
